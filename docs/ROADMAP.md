# TargetLens V1 路线图

## V1 已完成

- 靶点、疾病和药物形式归一化。
- 多来源研究预览、连接器状态和明确降级。
- 六部分靶点卡、证据来源和连续追问。
- 五维差异化建议、风险警示和雷达图。
- 会话消息、研究卡、证据快照和内部知识关系的数据模型。
- 本地注册、登录、演示模式及账号范围隔离。
- 公开只读成果库和 EGFR 教程练习。
- 前后端测试、类型检查、静态构建和本地 Compose 编排。

## 云端部署前必须完成

- 接入正式身份服务或企业 SSO，补齐组织、项目和审核权限。
- 使用云端 Secret Store，轮换所有开发阶段使用过的第三方密钥。
- 配置托管数据库、缓存、对象存储、备份和恢复演练。
- 增加 HTTPS、限流、审计日志、告警和可观测性。
- 建立连接器授权、调用限额、缓存和来源快照保留策略。
- 完成真实浏览器 E2E、并发、故障恢复和安全测试。
- 审核公开数据、第三方 API、公告和文献链接的使用条款。

## 后续方向

- 证据更新提醒和研究卡版本差异。
- 研发、医学、临床与 BD 的角色化评分权重。
- 人工复核工作流和可审计的结论签发。
- 报告导出、团队协作和企业知识库接入。
